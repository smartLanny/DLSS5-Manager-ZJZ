DLSS5 Manager 0.5 Beta6 · Unified5 自动配套测试分发包

解压完整目录到可写位置，再打开“DLSS 5 AI 超分管理器.exe”。
数据与组件保存在程序旁的 data 目录。升级前退出旧管理器，保留 data 和游戏备份。

首次使用：
1. 在组件管理中导入对应显卡的 RTX40 或 RTX50 DLC。
2. 添加游戏并确认图形接口；新装仍默认 0.4.7beta。
3. 要体验新 Core，选择“0.5 Unified5”，预览并应用后再启动游戏。
   管理器自动补齐匹配的 Bridge / Feeder，不用单独选择桥接器。
4. 改设置、切换版本或卸载前先退出游戏；应用不会自动启动游戏。

选用 Unified5 后：
- DX12 原生路线不安装额外 Bridge 或 Feeder。
- DX11 有原生输入时自动选择官方 Bridge 1.4.13-pre8。
- 无原生输入时使用接口匹配的 Feeder；Vulkan 使用随包 Vulkan Feeder profile。
- 兼容路线显示“实验支持”，不是额外的同意门槛，也不是所有游戏已通过的承诺。
- 只改变当前游戏的明确选择，不修改其他游戏、全局默认或已有安装。
- 旧专用配套若需更换路线，先在管理器恢复旧配套，再选择新版安装。
未知 API、真正不匹配的接口/位数或文件损坏仍会提示处理，不会强行混装。

完整 Unified5 Core、同源输入链和完整可选人脸后端已包含。
新版保守 / 颜色优先策略分别记忆强度。旧 INI 保留；独立人脸实验默认关闭。
0.3.3.4 / 0.3.3.7 原件未随本包提供；不把 0.3.7 改名冒充。

RenoDX Add-on 与显卡 DLC 独立导入；同一游戏不要同时启用多个 NR 消费者。
RenoDX 压缩包先解压，再在组件管理选择其中的 .addon64。
Full.zip 是管理器、RenoDX、RTX40、RTX50 四个包的合集；Windows VC++ x64 运行库单独提供。

建议测试：选 Unified5 → 确认预览所列 Core/API/组件 → 应用 → 启动游戏。
再测试修改颜色策略、卸载恢复、重新启动管理器后保持所选组合。
本包通过的自动测试不等于你的游戏已实测；问题请导出当前游戏的维护反馈。
启动无响应时运行“启动诊断.cmd”；不需要默认管理员模式或关闭沙箱。
