DLSS5 Manager 0.5 Beta5 · Unified5 测试分发包

解压完整目录到可写位置，再打开“DLSS 5 AI 超分管理器.exe”。
数据与组件保存在程序旁的 data 目录。升级前退出旧管理器，保留 data 和游戏备份。

首次使用：
1. 在组件管理中导入对应显卡的 RTX40 或 RTX50 DLC。
2. 添加游戏；新装默认 0.4.7beta。
3. 要体验新 Core，在“安装与启动”选择“0.5 Unified5”，应用后再启动游戏。
4. 改设置、切换版本或卸载前先退出游戏；应用不会自动启动游戏。

本次变更：
完整 Unified5 Core、同源输入链、匹配 DX11 载体与完整可选人脸后端。
新版保守 / 颜色优先策略分别记忆强度。旧 INI 保留；独立人脸实验默认关闭。
DX12 原生路线不安装额外 Bridge 或 Feeder。

兼容边界：
Core 外部 Provider 接口已有受控 GPU 证据，但不是所有游戏通过的证明。
现有 Feeder、Vulkan 配套保留自己的匹配 Core；不会因选择 Unified5 而偷偷混装。
官方 Bridge 是独立组件，不能把同名版本当成相同文件。本包不承诺所有 API 无痛兼容。

RenoDX Add-on 与显卡 DLC 均独立导入；同一游戏不要同时启用多个 NR 消费者。
Full.zip 只是管理器、RenoDX、RTX40、RTX50 四个包的合集。
Windows VC++ x64 运行库单独提供，不在 Full.zip 内。

启动无响应时运行“启动诊断.cmd”，先查看提示与日志；不需要默认管理员模式或关闭沙箱。
有问题请在维护页导出当前游戏反馈，并注明 Core、API、显卡和复现步骤。
