DLSS 5 AI 超分管理器 0.5 Beta4 · 本地候选

完整解压便携包后运行管理器，保留旧目录便于回退。程序数据在便携目录的 data 中。

1. 添加游戏，选择实际使用的图形接口。选择会单独保存，不要求先导入 DLC。
2. 在“安装与启动”选择 Core；在另外两页调整 NR 画面增强、DLSS 超分与补帧。
3. 点击“应用”。已有旧插件时先核对接管清单，再确认备份和替换；取消不会修改游戏文件。
4. 成功后主按钮变为“启动”，需要你再次点击才启动游戏。游戏运行中会等待退出，可随时取消等待。

缺运行库时按提示导入 DLC；取消保留选择，导入成功后继续原应用流程。
RTX 20/30/40 使用 RTX40 运行库 DLC，RTX50 使用 RTX50 DLC。显卡运行库与补帧组件是独立配套。
米哈游游戏保留独立入口，通过 HoYoShade 启动，共用三页设置。

Bridge、Feeder、MFG Unlock 与 RTX20/30 dlssg-sm86 随包提供。组件页显示实际文件状态，每类仅提示可用更新；文件已准备不代表当前 Core 已适配，更不代表实际补帧已验证。
新装默认 Core 0.4.7beta；0.5 D21 unified3（7a90660b）为主动选择的完整候选。当前没有纳入其他任务尚未交付的新 Core/Bridge/Feeder 适配。
RTX20/30 dlssg-sm86 固定 0.3.5 / 9621db57，使用上游 version.dll，不覆盖其他代理。默认 Optimized=1，倍率最多4×，实际由游戏决定；设置修改后重启游戏。

画质设置按实际 INI 读取。外部修改优先，受影响的草稿保留为可恢复备份；恢复草稿后仍需应用。减少层数不会清除各层参数。
高级设置、历史 Core、修复和诊断在游戏页按需展开；补帧不支持时仍可独立应用 NR 设置。

回退：先在 Beta4 取消等待操作，再按游戏使用历史 Core 或“恢复安装前”恢复备份。真正未完成的事务先走恢复入口。保留 _DLSS5_Backup、data 及使用中的组件库。
管理器本身回退：关闭 Beta4，重新打开保留的旧管理器目录。游戏回退建议先在 Beta4 内完成。

本候选通过的软件测试、Electron 交互与打包验证见配套验证记录；不冒充真实游戏测试。RTX5090 D 无法证明 RTX20/30 实际补帧效果；新版 Core 的 Bridge/Feeder 适配及相应游戏验证由其他任务继续。
