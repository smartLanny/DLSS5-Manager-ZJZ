DLSS 5 AI 超分管理器 0.4.9-beta.1 · D14 Core 测试版

本版把内置的 0.5 测试 Core 更新为 beta0.5-dline14，来源为
codex/050-corefix8-integration-20260911 的 build-r5 验证产物。
完整 ZIP 请全部解压后运行；便携 EXE 可单独运行。升级前正常退出旧管理器。

Core 测试入口
在普通游戏或米哈游设置的“增强版本”中可选择：
  0.5 D14 · 测试
  0.4.7 Corefix8 · 测试
它们只更新已有的原生 DX12 安装，使用各自配套的 Core 和 nrchain。
新安装仍默认使用 0.4.7beta；先完成 DX12 基础安装，再预览切换测试版本。
切换前退出游戏。现有 NR 配置、ReShade、NVIDIA Runtime 和游戏自带 DLSS 保留。
D14 与 Corefix8 都不带 DX11 carrier，不用于 DX11、Vulkan 或 Feeder 配套。
