DLSS 5 AI 超分管理器 0.5 Beta8 · 冲突处理与加载入口

只更新管理器，保留 Beta7 的 Core、Bridge、Feeder 和补帧配套。
新装默认 0.4.7beta；0.5 Unified5 仍需主动选择。显卡运行库通过 DLC 导入。

旧 NR 插件冲突：
点击“应用”后自动检查；发现冲突会列出文件和固定备份位置。
选择“备份冲突并应用”后才处理，取消不改游戏文件。
升级或更换 Core 不会放回隔离插件；卸载时选“恢复安装前”可恢复有记录的原文件。
“干净移除”保留隔离备份。装有当前配套时，不允许撤销环境清理把冲突文件放回来。
隔离目录来自所选程序的实际加载配置，不会仅凭文件名删除游戏原生 DLSS DLL。

DXGI 冲突：
异环 HTGame.exe 首次 DX12 安装默认 D3D12；已有安装保留当前入口。
其他 DX12 游戏在“安装与启动”点“改用 D3D12”，再点“应用”。
需要切回时点“改用 DXGI”并应用。较长说明放在按钮悬浮提示中。
目标入口已被其他文件占用时会提示，不直接覆盖；切入口不改画质配置。

文件被手动修改后卡住：在“维护与诊断”预览“修复运行目录”；
确有中断事务时用“处理未完成部署”。也可确认清理受管环境后重装。
“移出游戏库”只移出条目，游戏文件、备份和恢复记录保留。
游戏运行时可等待退出再应用；退出后重新检查，有新冲突会停下提示确认。
应用、修复、卸载成功都不会自动启动游戏。

升级：退出旧管理器，备份原目录，将新程序解压到原管理器目录，保留原位置的 data 与组件库。
不要先删除游戏组件，不要把 data 或 external-runtime 搬到新位置。
回退程序：先取消等待，退出 Beta8，使用保留的旧程序。保留 data、_DLSS5_Backup 和全部归档。
Beta8 产生的新隔离记录请用 Beta8 恢复，再回退程序。

本包是本地软件测试候选；真实异环、米哈游游戏和 RTX20/30 补帧仍需实际回测。
