DLSS5 Manager 0.5 Beta9

添加游戏，选择 Core 后点“应用”；完成后再点“启动”。
已有插件先确认备份，取消不会改动游戏文件。
运行中应用会等待退出；遇到新冲突可核对原来的待办继续操作。

Core 目录含 0.2.0-beta.2、0.3.7、0.4.2、0.4.7beta、0.5 D13、D21、Unified3、Unified5。
默认仍为 0.4.7beta；可用版本按实际配套显示，历史版本可用于回退。
旧“0.4.8-beta.3”是管理器版本，当时的 Core 仍为 0.4.7beta。
画面设置按实际 INI 读取；不支持的参数不显示。
在游戏或其他工具里改过配置后，外部修改优先，管理器会撤下对应的过期草稿。

米哈游与普通游戏共用“安装与启动／NR 画面增强／DLSS 超分与补帧”三页。
先核对启动器和游戏实际图形 API；无法识别时手动选择，再点“应用”。
已有原生 DLSS 时优先使用原生配套；DX11 自动匹配 Bridge，需要 Feeder 时匹配对应版本。
Unified5 与现有新版 Feeder 的米哈游适配已接入，不会自动用 Core 兼容模式替换 Feeder。
缺少运行库时按提示导入，再继续核对本次应用；无需反复导入来补其他缺件。
应用不会自动启动；单独设置超分或补帧也不要求先安装 Core。

升级管理器时保留原位置的 data 目录和全部备份；不迁移数据目录。
本轮仅更新管理器，未修改 Core、Bridge 或 Feeder。游戏效果与实际兼容性仍需按具体游戏验证。
