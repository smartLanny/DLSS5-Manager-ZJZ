DLSS5 Manager 0.5.2 Beta13

管理器版本和 Core 0.5.2 Beta 13 同步命名。
升级时保留原位置的 data 目录及全部备份。

用法：在“游戏”页左侧选中游戏，右侧点“安装”；装好后点“启动游戏”。
新游戏在“添加与扫描”页添加，也可以点搜索框旁边的“＋”。
每个游戏有四页设置：DLSS5、超分与补帧、启动与快捷键、高级。
DLSS5 页最上面是 DLSS5 开关和“恢复推荐画质”；下面的分组和名称与游戏内面板一致。
改了设置会出现“放弃修改 / 应用修改”；应用不会自动启动游戏。
左侧栏平时收起，鼠标移上去会展开。

新装默认用 Core 0.5.2 Beta 13，0.4.7beta 保留为稳定版；其他历史版本在“高级”页回退。
Beta 13 用现有的 DLSS5 模型就能装；有配套模型时可以另外导入，没有也不影响使用。
缺少 DLSS5 模型时按提示导入；DLSS5 页新增“低分辨率细节增强”和“去除暗噪”。
补帧默认使用 MFG Unlock 1.2.1，可设“帧率上限”；旧版本仍可在菜单里选。

米哈游游戏只在“米哈游”页设置，可选 0.4.7 和当前推荐的 Core。
画面设置以实际 INI 为准，在游戏里改过的设置优先。

RTX 20/30 版 Core 还没有在 20/30 系显卡上实测；实际游戏效果仍需按游戏确认。
