DLSS 5 AI 超分管理器 0.5 Beta3 · 本地实验候选

完整解压便携 ZIP 后运行“DLSS 5 AI 超分管理器.exe”。程序数据保存在便携目录旁；保留旧管理器目录，便于回退。本包不自动替换任何游戏文件。

添加与应用
选择游戏 EXE 后，API 手选会立即保存并绑定该 EXE。选择 API 不安装组件，也不修改游戏图形设置。无法明确识别时请按游戏实际设置选择。
页面显示当前改动，点击“应用修改”或“安装并启用”完成检查、备份和写入。缺少运行库时选择“导入运行库 DLC”；取消会保留选择，成功导入会继续上次应用。
RTX20/30/40 使用 RTX40 NR Runtime DLC，RTX50 使用 RTX50 DLC。运行库与补帧显卡代际分别判断。
游戏正在运行时显示“等待游戏退出”，可以取消。重启管理器会继续检查；外部文件或配置变化会停止该待办并保留原草稿。等待记录不是损坏或恢复事务。
应用期间可以查看其他游戏。实际文件冲突会显示具体原因；维护入口保留备份、恢复与反馈操作。

Core 与真实配置
新装默认 0.4.7beta。已有受管游戏保留实际版本，测试 Core 需要主动选择。
0.5 D21 unified3 固定采用 7a90660bc468ca86a02abe2e145638b51489d549 成品；旧 D21 保留回退。更新保留 INI，首次安装使用本成品完整模板与人脸资源。
画质页面按实际 Core 身份和活动 INI 显示。缺键、非法值、读取失败与已保存值分开说明，不将读取失败显示成旧默认值。
unified3 支持处理顺序、工作比例、1～5 层及各层模型/结构/色调/皮肤/UI 参数，以及最终增强与 AI 色彩。关闭后续层保留层内参数；“恢复本层默认”先形成草稿，应用后才保存。
游戏或其他工具修改配置后，以外部配置为准。受影响的未应用修改保存为“恢复原草稿”；恢复后需再次应用。配置解释值不等于游戏已经采用。
Feeder/Vulkan 继续使用有匹配接口证据的原配套。unified3 没有 NRExternalProviderV1 声明，不与不匹配的输入组件强行组合。

补帧
RTX20/30：独立 dlssg-sm86 0.3.5，来源固定为 sdli1995/dlssg_for_sm86 的 9621db573e07ed54f50c15bbb585ed9a7bdfac28。代理 version.dll、INI 和上游说明已随包准备。
Windows x64、DX12、游戏已有 FG 集成且硬件匹配时可启用。点击应用后安装；遇到其他 version.dll 不自动改名或覆盖。默认 Optimized=1，最多 4×；倍率是上限，实际由游戏决定。6× 仅在取得对应集成证据后开放，不启用强制插件补丁。设置修改后重启游戏。
RTX40：继续使用 MFG Unlock 1.0，0.9 保留回退。RTX50：继续使用原生方案。
“文件已准备”“组件已加载”“实际帧生成已验证”是不同状态。此候选未完成 RTX20/30 实际补帧与 unified3 游戏验证。

恢复与回退
更换 Core 前会保留原安装记录与备份；可重新选择旧 Core 应用。维护中“干净移除”移除摘要一致的受管文件，“恢复安装前”按备份恢复原件。未知文件或外部改动不会直接删除。
出现真正未完成写入时，先用对应恢复入口。不要手动删除 _DLSS5_Backup、便携 data 或仍被使用的组件库。
管理器自身回退：退出 Beta3，重新运行保留的旧管理器；Beta3 的等待任务请先取消。游戏回退应在 Beta3 中完成，避免旧管理器无法识别新增组件。

验证边界与说明
本地软件测试、Electron 交互、构建验证与真实游戏结果分开记录。RTX5090 D 不能代替 RTX20/30 补帧验证。反馈时附游戏、显卡、API、Core、具体步骤及管理器导出的诊断。
第三方组件说明分别位于 resources/fg-sm86、resources/fg-mfgunlock 与 Core 的 nr_face 目录；管理器 MIT 许可不会覆盖其中的 NVIDIA 等第三方载荷。
