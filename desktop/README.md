# DLSS 5 AI 超分管理器 · 桌面版

这是装机宅管理器的桌面应用：查找游戏、管理画面增强组件、预览设置，并在出现问题时检查和恢复。

**普通用户请从[项目首页](../README.md)下载应用，并阅读[使用指南](../docs/USER-GUIDE.md)。** 当前文件夹是源码，不能把下载整个文件夹当作安装完成。

新 UI 测试请看[验证包使用说明](../docs/PR5-TESTING.md)。外部组件版需要已有的完整组件目录；不会因为换界面就自动替换旧游戏的 Core、桥接器或 HoYoShade 启动方式。

开发、测试和打包命令已经独立放到[开发指南](../docs/DEVELOPMENT.md)、[UI 开发文档](../docs/UI-DEVELOPMENT.md)和[打包文档](../docs/MANAGER-PACKAGING.md)。源码归属见 [UPSTREAM.md](UPSTREAM.md) 和 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
