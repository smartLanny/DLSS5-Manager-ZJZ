# Manager 0.5 Beta8：隔离冲突与简化加载入口

从已交付 Beta7 `d6e093c1ab1483b28213357727235c7f956533ab` 隔离接续，仅修改管理器。Core、Bridge、Feeder、补帧组件及 DLC 继续使用原固定文件；默认 Core 仍为 `0.4.7beta`。未发布、推送或合并，也未操作真实游戏目录。

## 使用变化

- 安装和更新遇到活动 NR 插件冲突，先显示“备份冲突并应用”，列出固定备份目录；取消保留草稿，文件不变。
- 外置目录后来新增的插件也重新核对；普通游戏和 HoYoShade 共用检测。明确 NR 自声明优先于旧的保留选择；普通插件的既有路径与摘要匹配时保留原选择。
- Core 更新和更换保持隔离。卸载“恢复安装前”按已核实的备份恢复，固定备份继续保留；当前配套未卸载时，环境撤销不能放回冲突文件或隐式卸载。
- 外置安装迁回游戏目录时，隔离记录随部署移交；确认框显示新的卸载恢复位置。自定义外部 Add-on 目录继续保留既有边界，不能转普通目录时可继续外置，或先卸载恢复原位。
- 异环所选程序 `HTGame.exe` 首次 DX12 安装默认 D3D12。已有安装及明确手选优先；没有改变图形 API 识别或渲染算法。
- 安装页用“改用 D3D12 / 改用 DXGI”按钮暂存入口，统一“应用”后生效。HoYoShade 与加载助手不显示代理按钮。目标已占用时拒绝覆盖；DX11 选择同步切回 DXGI。
- 历史上直接接管的 D3D12 入口也可切换、修复及更新；原始备份的路径不随当前加载入口变化。
- 等待游戏退出时重新检查；新冲突或文件变更要求重新确认，旧确认绑定文件摘要和加载配置。

## 本地验证

使用真实 Electron、生产界面、应用服务、队列、安装器和文件事务，游戏程序、GPU、Core 字节为不执行的测试夹具。新增交互链验证取消零写入、默认 D3D12、入口切换、Core 往返、INI 精确字节保留、冲突隔离、升级不恢复和卸载还原；全程没有自动启动。

相关单元及集成验证覆盖外置与 HoYoShade 新增插件、旧版本收据迁移、明确 DLL 加载项、失败回退、占用保护、备份篡改、运行中确认与恢复门禁。原生加载测试中的真实 PR160 工具项因未提供该独立工具跳过，未计为通过。

最终源码身份、各组实际通过/跳过数量、新包逐文件和 ZIP 校验、启动验证及私有证据位置记入交付目录 `source-manifest.json` 与 `validation.json`。相关测试组存在交集，不相加为独立覆盖数量。未把本次局部回归记作全桌面套件通过。

## 升级与回退

退出旧管理器，备份其目录，将新程序放回原管理器目录，保留原位置的 `data` 和组件库。不要预先删除游戏文件或移动外置运行目录。

回退程序前取消待应用操作；Beta8 新产生的隔离记录先用 Beta8 恢复，再运行保留的旧程序。`_DLSS5_Backup`、`data/external-runtime` 及相关事务归档均应保留。

实际异环、米哈游游戏、NVIDIA 推理和 RTX20/30 补帧仍待实机回测。本次未运行托管 CI，未承诺所有第三方插件都已识别或验证兼容。
