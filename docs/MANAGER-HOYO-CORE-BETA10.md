# Manager Beta10: available HoYo Core choices

Based on the local Beta9 candidate `72f2ba6b6b56d7d1e022bcb1dc882d02af23c45d`.

HoYo's dedicated and ordinary game editors offer only the actual 0.4.7 Core and
the current Unified5 candidate for new installations and Core changes. Older
Core builds remain available to ordinary games. A historical HoYo installation
keeps its displayed identity and its configuration, repair, restore and uninstall
paths; changing the menu never replaces its files or recovery receipts.

Native DLSS remains the preferred input, with a matching Bridge for DX11.
The current Feeder packages require capabilities not declared by the standard
0.4.7 Core, so the Feeder choice uses Unified5. Missing payloads, mismatched
Bridge/Provider identities and unsupported APIs still go through existing checks.
The shared menu policy does not grant compatibility based on a version label.

Unavailable explicit drafts remain visible for correction. Automatic defaults
may choose Unified5 for a new Feeder installation, but no files change until Apply.
HoYo install/update previews also enforce the target policy. The internal repair
path retains the exact installed Feeder package rather than pretending it is a
new selectable Core. Historical Manager 0.4.8-beta.3 is not a separate Core.

Validation covers real Electron editors and production service transactions in
synthetic game directories with actual staged component files. The delivery's
source manifest and validation record identify final outputs and results. There
is no game execution, component rebuild, Release publication or branch merge.
