# 使用指南

## 先准备什么？

使用 Windows 10/11 电脑，下载项目发行页或维护者提供的应用包。需要哪类显卡、哪套运行库，以对应组件包的说明为准；管理器能打开不代表显卡能够运行所有画面增强功能。

首次测试先选一款允许使用模组的离线游戏，退出游戏后再安装或换版。保留原管理器、完整组件目录和恢复记录。

## 找到游戏

在“游戏库”点击“扫描本机”。没有找到时，用“添加游戏”选游戏文件夹，或者用“选择 EXE”选择真正运行游戏的程序。

启动器和游戏本体可能在不同目录。选中后核对界面中的路径和图形接口；多个 EXE 或多个接口时，按游戏实际启动方式选择。选了 DX12 并不表示管理器会对任何启动器自动添加 `-dx12` 参数；未知游戏不要猜参数。

米哈游游戏使用专门页面，核对客户端、渠道和启动器绑定，保留原来的 HoYoShade 方式。

## 准备安装组件

到“组件管理”查看“安装组件来源”。已有完整组件目录时，选择该目录并等待检查。切换来源本身不会立即改动游戏。

完整组件目录用于首次安装和修复；单个 addon 或更新包只更新指定部分，不能代替完整组件。显示“组件未准备”时先补齐来源，不要把不明 DLL 改名后放进去。

Bridge 和 Feeder 是帮助不同游戏接入的兼容组件，不是两个都装才更好。使用与所选游戏接口、Core 和架构匹配的配套；已有兼容组合先保留，不盲追最新版。

## 安装、设置和切换版本

展开游戏卡片，先确认 Core 版本和接口。改变参数后先查看预览，核对游戏路径、将替换的文件和风险提示，再明确应用。取消预览不会执行安装。

已安装游戏不会仅因管理器升级就切换到新的默认 Core。缩短版本菜单也不会把正在用的 D12 等旧版本换掉。新版本缺文件或未满足兼容条件时，不应强行绕过提示。

SR 是超分辨率，FG / MFG 是补帧。相应控件是否可用取决于显卡和游戏入口；能选择、文件已安装、组件已加载和游戏画面确实变化是不同状态。

## 发生问题时

先停止重复安装并退出游戏，到“检查与修复”核对安装记录。使用管理器提供的恢复入口；尚未结束的操作先等待，已失败的操作按提示恢复。

不要手工删除不认识的 `dxgi.dll`、`d3d12.dll`、`version.dll` 或 Addon，它们可能属于别的模组。第三方文件需要逐项确认，不能当作垃圾一起清理。

反馈中写清游戏、显卡、管理器和 Core 版本、图形接口、启动方式，以及“做了什么之后出了什么问题”。优先用管理器预览并脱敏导出的反馈，必要时附 F8 记录及同场景开关对比；不要直接上传账号信息或完整用户目录。

## 从旧版升级

先关闭旧管理器，但不要删除旧程序和组件目录。新 UI 验证包先放在独立目录运行，检查游戏列表、Core 版本、API、设置、HoYoShade 绑定及恢复入口。

portable 版只是免安装，可能继续使用已有设置；要测旧配置升级，应先备份配置再运行，不能把免安装当作完全隔离。external 版不带 Core 和运行库，旧版随程序提供的完整组件目录需要保留并重新选择为来源。

详细验证步骤见[新 UI 测试指南](PR5-TESTING.md)。
